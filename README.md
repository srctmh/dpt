# MAX Protection v4.0.0

Professional APK protection tool for Termux  
**by SRC TMH**

## Install

```bash
pkg install git -y
git clone https://github.com/srctmh/maxdpt.git
cd maxdpt
bash install.sh
```

Then:

```bash
maxdpt
```

## Features

- Library Protect (optional)
- Resource Protect (optional)
- MAX engine (Normal / Signature Plus / Skip)
- Credits system (starts at 0)
- Device ID auto-copy on credit redirect
- Full temp cleanup after every run

## Output

`/storage/emulated/0/@SRCTMH/`

## Credits

- Minimum 1 credit to start Protect
- Normal → 1 credit
- Signature Plus → 2 credits
- Skip MAX → 1 credit

Get credits: option **[3] Get Credits** or when balance is low.

## Admin

Open `admin/index.html` in browser
